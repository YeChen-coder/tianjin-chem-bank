## 答题空与中文来源修复

用户截图中的题目由下划线、不换行空格及多个 Word run 拼成答题空，原网页按字符显示而断开。网页现使用连续线条显示，并合并相同格式的相邻文字；Word 导出使用带单下划线格式的不换行空格。导入也补充识别 Unicode 空格的下划线。旧库中的间隔下划线可直接显示和导出，无需重建题库。

三份源 DOCX 的磁盘文件名本身存在乱码。显示来源时优先读取文件内明确的中文标题，同时标明“原文件名编码异常”；原路径保留在来源提示中。没有可靠标题时显示“未命名来源”，不猜造中文原文件名、不重命名原文件。中文文件名上传、存盘、接口响应和 Word 来源导出均有回归验证。

开发题库第 53 题从其原始文档重新提取了此前遗漏的不换行空格答题线。仅更新这一条未手工改写的开发样本，保留 ID 与用户试卷的五条关联；更新前的开发库备份在 `.dev/data/bank.before-display.sqlite`。浏览器确认有七处连续答题空、中文文档标题，以及题目内容无横向溢出。验证导出 `.dev/data/display-fixed.docx` 有七处原生单下划线 run，中文来源保留。正式库和六个受保护文件再次核对均未改变。
